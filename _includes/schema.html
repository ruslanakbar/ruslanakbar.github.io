{%- comment -%} Identity data for search engines (schema.org "Person", read by Google). It states who this site belongs to, other spellings of the name, and which profiles elsewhere are the same person. Nothing here is visible on the page. This file replaces the theme's own _includes/schema.html, which only gives the name. The values come from `author:` and `identity:` in _config.yml. {%- endcomment -%} {%- assign identity = site.identity -%} {%- assign profiles = "" | split: "" -%} {%- if site.author.linkedin -%} {%- assign profile = "https://www.linkedin.com/in/" | append: site.author.linkedin -%} {%- assign profiles = profiles | push: profile -%} {%- endif -%} {%- if site.author.github -%} {%- assign profile = "https://github.com/" | append: site.author.github -%} {%- assign profiles = profiles | push: profile -%} {%- endif -%} {%- for profile in identity.profiles -%} {%- assign profiles = profiles | push: profile -%} {%- endfor -%}
